# Rithik Anand — Personal Portfolio

A personal portfolio website showcasing my work, experience, projects, technical skills, education, and achievements in Data Science, Machine Learning, and Analytics.

🔗 **Live Portfolio:** https://rithik-anand-nitt.vercel.app/

---

## 📌 Overview

This portfolio serves as a central place to explore my academic background, professional experience, technical projects, and leadership activities.

I am an Electrical and Electronics Engineering undergraduate at **NIT Tiruchirappalli**, also pursuing a **B.Sc. in Data Science and Applications from IIT Madras**.

My interests include Data Science, Machine Learning, Natural Language Processing, Generative AI, Agentic AI, and Data Analytics.

The website is designed with a clean, minimal, editorial-style interface to present my work and experience in a structured and accessible manner.

---

## ✨ Features

- **Personal Introduction:** Overview of my academic background, interests, and professional focus.
- **Education:** Highlights my academic journey at NIT Trichy and IIT Madras.
- **Professional Experience:** Showcases my internship and research experience.
- **Featured Projects:** Displays selected projects across Machine Learning, NLP, Generative AI, and Analytics.
- **Technical Skills:** Organised overview of programming languages, frameworks, databases, and tools.
- **Leadership & Achievements:** Highlights my contributions to DataByte and competitive achievements.
- **Contact Section:** Direct links to email, GitHub, and LinkedIn.
- **Responsive Design:** Optimised for desktop, tablet, and mobile devices.

## 💻 Getting Started

Follow these steps to run the portfolio locally.

### 1. Clone the Repository

```bash
git clone https://github.com/rithik2812/portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd portfolio
```

### 3. Run the Website

Open `index.html` directly in your browser.

Alternatively, use the **Live Server** extension in Visual Studio Code for local development.
